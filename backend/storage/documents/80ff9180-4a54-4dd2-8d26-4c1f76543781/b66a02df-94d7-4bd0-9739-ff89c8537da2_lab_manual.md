# Quantum Computing Laboratory Manual

## Section 1: Bell State Generation
To generate the canonical Bell state |Phi+> = (|00> + |11>)/sqrt(2), apply a Hadamard gate to qubit q0, followed by a CNOT gate with control q0 and target q1.
